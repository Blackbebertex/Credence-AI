# ADR-0001: P0 is synthetic-data-only

- **Status:** Accepted for P0 only
- **Date:** 2026-10-09
- **Decision:** Build local development foundations without accepting or storing real government evidence. External LLM/search and all autonomous actions remain disabled.
- **Reason:** Pilot owner, classification, retention, legal hold, key custody, hosting, egress, and counsel-cleared charter are unresolved in the source blueprint.
- **Consequences:** P0 may prove service boot and developer workflow only. It cannot establish legal, security, scientific, operational, or pilot readiness. Pilot decisions remain required before operational data.
- **Review trigger:** R0 gate completion and a named pilot owner/security officer/counsel review.
